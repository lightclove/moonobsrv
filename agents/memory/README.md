# memory.json — граф памяти MCP `memory` для агентов moonobsrv

Файл — хранилище знаний (knowledge graph) MCP-сервера `memory`: переживает
сессии агентов, пополняется через инструменты `create_entities` /
`create_observations`. Сюда агенты записывают факты о проекте, чтобы не
переоткрывать их каждый раз.

Схема сущностей (заводить при первом упоминании):

| Тип сущности | Имя | Что в наблюдениях |
| --- | --- | --- |
| `project` | `moonobsrv` | стек, версии, архитектура, конвенции |
| `component` | `moonobsrv/<слой>/<модуль>` | роль, инварианты, известные грабли |
| `bug` | `BUG-NNN` | суть, фикс, профилактика |
| `release` | `vX.Y.Z` | что вошло, дата |
| `decision` | `D-NN-<slug>` | архитектурное решение, почему, кем |
| `agent-session` | `S-<дата>-<роль>` | что делали, чем кончилось |

Правила:

- Записывать **факты, а не пересказы**: «TLS-буферы ≥17 КБ — иначе UB в
  ReleaseSmall» — да; «много всего про сеть» — нет.
- Наблюдения короткие, по одной мысли. Дубли не создавать — сначала поиск.
- Устаревшее помечать наблюдением `obsolete: <дата>, причина`, не удалять.
- Секреты (токены, пароли, IP+порты прода) — **никогда**.
