# TESTCASES_AAA.md — тест-кейсы moonobsrv (формат AAA)

Документ системного аналитика к `FEATURES.md` (версия 1.1.0, 2026-09-09).
Каждый кейс: **A**rrange (входные данные/состояние) → **A**ct (действие) →
**A**ssert (ожидание). Идентификаторы `TC-NNN` привязаны к фичам `F-NN`.

Тип прогона: **U** — юнит (zig-тест/зонд против модуля, без сети),
**C** — CLI (запуск бинаря), **B** — black-box бота (нужен Telegram;
выносится в MANUAL_TESTING.md), **S** — статический аудит кода.

Допуски взяты из заявленной точности модели (README «Точность и соглашения»):
Луна ±0.05°, Солнце ±0.01°, планеты — угловые минуты, моменты переходов —
единицы минут модельного времени; якоря новолуний ±15 мин, восходы ±10 мин,
ретро-станции ±36 ч.

---

## Раздел 1. Астроядро: время и углы (F-01, F-02)

### TC-001 [U] jd ↔ Unix в обе стороны
- Arrange: t0 = 1_773_000_000 (unix).
- Act: jd = jdFromUnix(t0); back = unixFromJd(jd).
- Assert: |back − t0| ≤ 0.001 с.

### TC-002 [U] daysFromCivil на эпохах
- Arrange: даты 1970-01-01, 2024-01-01, 2026-08-12.
- Act: daysFromCivil по каждой.
- Assert: 0; 19723; 20686 (20686 = 19723 + 963 дня, проверяется независимо
  календарём: 2024-01-01 + 366 + 365 + 212 = 2026-08-01, +11 = 08-12).

### TC-003 [U] gmstDeg на J2000
- Arrange: jd = 2451545.0.
- Act: gmst = gmstDeg(jd).
- Assert: gmst ≈ 280.46061837 (mod 360), |Δ| < 1e-6.

### TC-004 [U] wrap180/wrap360 значения
- Arrange: x ∈ {0, 180, −180, 190, 350, 720, −190}.
- Act: wrap360(x), wrap180(x).
- Assert: wrap360 → {0, 180, 170, 190, 350, 0, 170};
  wrap180 → {0, 180, 180, −170, −10, 0, 170}.

### TC-005 [U] nextZero на эталонной пиле
- Arrange: f(t) = wrap180(t − 100.0) на [50, 150] (нулевой переход при t=100).
- Act: z = nextZero(F, f, 50, 150).
- Assert: |z − 100| < 1e-6.

### TC-006 [U] bisectSign на синусе
- Arrange: g(t) = sin((t−2)·π/8), отрезок [0, 4] (ноль при t=2).
- Act: r = bisectSign(F, g, 0, 4).
- Assert: |r − 2| < 1e-6.
