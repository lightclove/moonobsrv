# BUG-063 — cmdRestart: no-op setUpdateCursor(updateCursor()) на бутлуп-критичном пути

- Статус: ЗАКРЫТ (был ОТКРЫТ, закрыт 2026-09-10)
- Фикс: `src/features/monitor.zig` (строка удалена)
- Открыт: 2026-09-10
- Где найдено: код-ревью (ночной аудит фич)
- Серьёзность: низкая

## Симптом

Перед docker-restart выполнялась запись курсора самого в себя — код-обманка
в месте, где читатель ожидает осмысленную анти-бутлуп операцию (видимо,
замышлялось +1).

## Причина

Недописанная строка; реальная защита — ACK выше по коду и inflight-яд в
polling-цикле, поэтому безвредно.

## Лечение

Строка удалена (поведение не изменилось — значение не менялось).

## Профилактика

Ревью-внимание к «запись X в X» в критичных путях.
