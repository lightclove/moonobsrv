# BUG-052 — dockerHttp обрезал ответы Docker > 64 КиБ: ложные «все контейнеры упали»

- Статус: ЗАКРЫТ (был ОТКРЫТ, закрыт 2026-09-10)
- Фикс: `src/bot/wd.zig` (буфер растёт 64 КиБ → 1 МиБ в арене вызывающего)
- Открыт: 2026-09-10
- Где найдено: код-ревью (ночной аудит сторожей)
- Серьёзность: низкая

## Симптом

На хосте с десятками контейнеров ответ /containers/json превышал стековый
буфер 64 КиБ — чтение останавливалось без EOF, усеченный JSON не парсился,
parseContainers возвращал пусто → hostwatch два среза подряд видел
bot/db/tor=false → дебаунс «подтверждал» падение → ложные алерты.

## Причина

Фиксированный `[64 * 1024]u8` без обнаружения переполнения.

## Лечение

Буфер в арене вызывающего с удвоением до 1 МиБ; свыше — честный null.

## Профилактика

Ревью-правило: буфер отклика внешнего API — либо с ростом, либо с детектом
усечения.
