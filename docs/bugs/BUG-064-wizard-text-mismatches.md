# BUG-064 — тексты слайдов гида и /subscribe расходились с фактическим поведением

- Статус: ЗАКРЫТ (был ОТКРЫТ, закрыт 2026-09-10)
- Фикс: `src/features/wizard.zig` + `src/features/service.zig` (7 правок текста)
- Открыт: 2026-09-10
- Где найдено: код-ревью (сверка слайдов с кодом фич)
- Серьёзность: низкая

## Симптом

Семь расхождений документации с фактом:
1. «/day — синонимы /moon, /луна» — пропущен /lunday (реестр);
2. «/planets: Меркурий…Сатурн» — фактически 8 тел, до Плутона;
3. админ-слайд: «промежутки по каждому слою» — только для «процесса»;
4. слайд подписки и ответ /subscribe обещали 3 вида уведомлений —
   ватчеры шлют ещё и станции Венеры/Марса/Юпитера/Сатурна;
5. цитата «Заявка отправлена. Ждите решения.» не совпадала ни с одним
   реальным текстом (дословно — «Заявка отправлена админу. …»);
6. «Вернуть гид: /wizard или /start» — /start шлёт приветствие с кнопкой,
   а не сам гид;
7. «титхи от ~21 до ~26 часов» — измеренный минимум 20.1 ч.

## Причина

Тексты писались до/вне кода и не сверялись при эволюции фич.

## Лечение

Все семь мест выверены по коду (см. дифф wizard.zig/service.zig).

## Профилактика

Существующий тест «пользовательские слайды не протекают админскими
командами» расширен быть не может на смыслы — правило: правка поведения
фичи тянет за собой правку слайдов в том же ходе (записано в AGENTS-практику).
