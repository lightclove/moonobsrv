# BUG-060 — лунные сутки «от восхода» вымирают уже с ~62–65° с.ш.

- Статус: ЗАКРЫТ (был ОТКРЫТ, закрыт 2026-09-10)
- Фикс: `src/astro/rise.zig` (окно скана 1.3 → 10 сут) + `src/astro/lunday_rise.zig` (пауза восходов ≠ смерть системы) + тест
- Открыт: 2026-09-10
- Где найдено: зонды по 2026 (65° — валиден лишь 12% часов, 78° — 2%)
- Серьёзность: средняя

## Симптом

У Архангельска (64.5°), Салехарда (66.5°), Мурманска/Норильска (69°) блок
«🌄 По восходам Луны» отсутствовал почти всегда: на высоких широтах
интервалы между восходами превышают окно поиска 1.3 сут, а пропавший
промежуточный восход ронял ВСЮ систему до null — даже когда текущие сутки
уже определены.

## Причина

nextRise искал восход только в 1.3 сут (хватает для средних широт);
lunday_rise делал `orelse return null` на любом пропавшем промежуточном
восходе.

## Лечение

Окно скана — 10 суток (скан останавливается на первом пересечении: для
Москвы стоимость та же); пауза восходов — текущие сутки тянутся до
новолуния (что семантически верно), null остаётся только когда восходов
нет вовсе (полярная ночь Луны после новолуния).

## Профилактика

Тест «лунные сутки от восхода: высокие широты» (Архангельск/Мурманск,
15.06.2026).
