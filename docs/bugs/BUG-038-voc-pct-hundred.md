# BUG-038 — /voc: «пройдено 100% знака» до фактической ингрессии

- Статус: ЗАКРЫТ (был ОТКРЫТ, закрыт 2026-09-10)
- Фикс: `src/features/voc.zig` (`pct`: потолок 99) + тест
- Открыт: 2026-09-10
- Где найдено: прод (наблюдение в живом выводе `--today` вечером 09.09)
- Серьёзность: низкая

## Симптом

В конце прохождения знака вывод противоречил сам себе:

```
♌ Лев — пройдено 100% знака
Вход в Деву: 9 сентября, 22:36 (через 13 мин)
```

— при 99,6% округление `pct` (x+0,5) давало 100%, хотя Луна ещё в знаке.

## Причина

`fn pct(x) = intFromFloat(max(0, x + 0.5))` — без потолка; прогресс в знаке
строго < 100%, значит «100%» всегда означает округление, а не факт.

## Лечение

Потолок 99: `@min(@max(0, x + 0.5), 99)`. Тест на границы (−5 → 0,
99,9 → 99).

## Профилактика

Тест `pct: округление и потолок 99` в `features/voc.zig`.
