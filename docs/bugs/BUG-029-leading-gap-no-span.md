# BUG-029 — /idle*: ведущий гэп учтён в сумме простоя, но не в списке «с … по …»

- Статус: ЗАКРЫТ (был ОТКРЫТ, закрыт 2026-09-09)
- Фикс: `src/bot/mon.zig` (`addSpan` для ведущего гэпа) + тест
- Открыт: 2026-09-09
- Где найдено: код-ревью (злой QA)
- Серьёзность: низкая

## Симптом

Суммарный простой процесса включает время от начала окна до первого
сэмпла (если > 150 с), но в списке промежутков этого интервала нет —
число и расшифровка расходятся, админ не видит, когда именно висело.

## Причина

`src/bot/mon.zig:289-291`: ведущий гэп суммируется в `proc.down` без
`addSpan` (хвостовой гэп, строки 307-309, — вызывает).

## Лечение

`st.proc.addSpan(from, samples[0].ts)` для ведущего гэпа (addSpan сам
склеит с соседним при необходимости).

## Профилактика

Тест: окно 1000..2000, единственный сэмпл на 1600 → proc.down == 600 и
span_n == 1 с границами 1000–1600.
