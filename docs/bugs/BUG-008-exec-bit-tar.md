# BUG-008 — exec-бит теряется в tar из Windows

- Статус: ЗАКРЫТ (было ОТКРЫТ, закрыт 2026-09-09)
- Открыт: 2026-09-09
- Где найдено: прод (старт контейнера бота)
- Серьёзность: средняя
- Фикс: `Dockerfile` (`RUN chmod 0755 /moonobsrv`)

## Симптом

`exec: "/moonobsrv": permission denied` при старте контейнера.

## Причина

Файловые системы Windows не хранят Unix-биты; tar, собранный на Windows,
кладёт 0644. ENTRYPOINT без права на исполнение не стартует.

## Лечение

`chmod 0755` прямо в Dockerfile после COPY.

## Профилактика

Правило: любой исполняемый файл, приезжающий из Windows-тарболла, получает
chmod в образе. Скрипты на Arch-стороне — `chmod +x ci/*.sh` в deploy.
