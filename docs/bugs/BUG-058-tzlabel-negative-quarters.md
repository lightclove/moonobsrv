# BUG-058 — tzLabel: отрицательные не-:30 пояса печатались как «UTC-13:15» вместо «UTC-13:45»

- Статус: ЗАКРЫТ (был ОТКРЫТ, закрыт 2026-09-10)
- Фикс: `src/util.zig` (часы/минуты от модуля смещения) + тест
- Открыт: 2026-09-10
- Где найдено: код-ревью + зонд (ночью; BUG-017 закрыл только ±:30)
- Серьёзность: низкая

## Симптом

`MOONOBSRV_TZ=-13.75` (Чатем) → /status и лог старта показывали
«UTC-13:15»: divTrunc(−49500, 3600) = −13 (усечение к нулю), а
mod-остаток +900 с → 15 мин. Для :30 совпадение (30 самодополняемо),
для :45 — сдвиг на 30 минут.

## Причина

Смешанная арифметика: часы усечением, минуты — положительным модулем.

## Лечение

Часы и минуты считаются от `@abs(off_sec)`; знак — только для вывода.

## Профилактика

Тест tzLabel на −13:45 и −8:45.
