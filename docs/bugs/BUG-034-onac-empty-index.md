# BUG-034 — чтение online-файла питания: индекс [0] по пустому файлу — паника/UB

- Статус: ЗАКРЫТ (был ОТКРЫТ, закрыт 2026-09-09)
- Фикс: `src/features/monitor.zig` + `src/hostwatch.zig` (проверка длины после trim)
- Открыт: 2026-09-09
- Где найдено: код-ревью (злой QA)
- Серьёзность: низкая

## Симптом

Пустой `/sys/class/power_supply/*/online` (битый сенсор, races в sysfs)
даёт панику в Debug/ReleaseSafe и чтение за границей в ReleaseSmall
(прод) — процесс умирает, Docker поднимает; в /monitor и hostwatch.

## Причина

`src/features/monitor.zig:301` и `src/hostwatch.zig:239`:
`std.mem.trim(...)[0] == '1'` без проверки длины.

## Лечение

`const s = trim(...); return if (s.len == 0) null else s[0] == '1';`

## Профилактика

Модуль читает sysfs — юнит не построить без моков ФС; правило ревью: любой
`x[0]` после trim/чтения файла сопровождать проверкой len (фикс — тривиален,
проверяется просмотром).
