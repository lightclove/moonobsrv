# BUG-051 — dockerRestart сообщал успех («команда ушла в Docker»), когда запрос не отправлен

- Статус: ЗАКРЫТ (был ОТКРЫТ, закрыт 2026-09-10)
- Фикс: `src/bot/wd.zig` (dockerHttpEx с флагом wrote: не отправлено → .no_docker, отправлено без ответа → .sent)
- Открыт: 2026-09-10
- Где найдено: код-ревью (ночной аудит сторожей)
- Серьёзность: низкая

## Симптом

При полном обрыве (сокета нет/запись не прошла) `/restart*` отвечал админу
«команда ушла в Docker (ответа нет — так бывает…)» — ложное благополучие:
команда не отправлялась вовсе.

## Причина

`dockerHttp` возвращал null и когда соединение НЕ установлено, и когда
ответа нет — dockerRestart сваливал оба случая в `.sent`.

## Лечение

dockerHttpEx с выходным флагом «запрос физически записан в сокет»:
false → .no_docker, true → .sent.

## Профилактика

Ревью-правило: результат «отправлено» подтверждается фактом записи, а не
отсутствием ответа.
