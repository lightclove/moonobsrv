# BUG-036 — planRestart: 90-секундный кулдаун не работает в командном пути (мёртвая ветка)

- Статус: ЗАКРЫТ (был ОТКРЫТ, закрыт 2026-09-09)
- Фикс: `src/bot/rst.zig` (`skipRepeat`: кулдаун проверяется и при свежей команде) + тест
- Открыт: 2026-09-09
- Где найдено: код-ревью (злой QA, TC-146)
- Серьёзность: низкая

## Симптом

Два подряд `/restarttor` (или `/restart`) от админа в пределах 90 с оба
исполняются — заявленный README «кулдаун рестартов 90 с» держится только
для авто-рестарта Tor после неудач getUpdates, не для команд.

## Причина

`src/bot/rst.zig:113-117`: `skipRepeat` проверяет `bounce_age` только
при `msg_date == 0`, а единственный прод-вызов (monitor.zig:111) всегда
передаёт `ctx.base.now > 0` — ветка кулдауна мертва. Тест планa вызывает
её только с msg_date=0.

## Лечение

Проверять оба условия независимо: replay (msg_date < started) ИЛИ свежий
маркер рестарта (bounce_age < 90 с) → skip_stale; текст отказа уже есть
(«повтор /restart … пропущен»).

## Профилактика

Тест: planRestart с msg_date > started и bounce_age=10 → skip_stale
(сейчас — bounce).
