# BUG-028 — /idle*: ветка «нет данных» недостижима — не наблюдавшийся слой рисуется как «0 · 100%»

- Статус: ЗАКРЫТ (был ОТКРЫТ, закрыт 2026-09-09)
- Фикс: `src/bot/mon.zig` (условие без мёртвого `denom == 0`) + тест
- Открыт: 2026-09-09
- Где найдено: код-ревью (злой QA)
- Серьёзность: низкая

## Симптом

Если за окно все интервалы между сэмплами — гэпы > 150 с (бот надолго
висел), каждый слой печатается «• postgres — 0 · 100%», хотя наблюдений
нет вовсе и 100% — ложь.

## Причина

`src/bot/mon.zig:366`: условие `s.obs == 0 and s.down == 0 and denom == 0`,
но `denom = @max(win.to − win.from, 1) ≥ 1` всегда — третья проверка
лишняя и делает ветку мёртвой.

## Лечение

Условие без `denom == 0`: `s.obs == 0 and s.down == 0` → «нет данных».

## Профилактика

Тест computeStats/fmtIdle: два сэмпла в 600 с друг от друга → строка
слоя содержит «нет данных».
