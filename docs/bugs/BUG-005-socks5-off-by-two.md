# BUG-005 — off-by-2 в длине доменного ответа SOCKS5

- Статус: ЗАКРЫТ (было ОТКРЫТ, закрыт 2026-09-09)
- Открыт: 2026-09-09
- Где найдено: тесты
- Серьёзность: средняя
- Фикс: `src/net/socks5.zig` (`parseReply`)

## Симптом

Юнит-тест «неполный кадр → null» не проходил: доменный ответ считался
полным раньше времени (при недоборе 2 байт).

## Причина

Формула полноты кадра ATYP=0x03 считала `7 + len` вместо
`5 + len + 2` (5 байт заголовка + домен + 2 байта порта). Классический
off-by-two от невнимательности к собственному комментарию.

## Лечение

`data.len >= 5 + data[4] + 2`. Буфер приёма поднят до 262 (домен 255).

## Профилактика

Тест-таблица в `socks5.zig` перебирает все ATYP (IPv4/домен/IPv6) и
граничные случаи; off-by-N теперь ловится байт-в-байт эталоном.
