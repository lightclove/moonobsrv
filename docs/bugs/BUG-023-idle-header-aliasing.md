# BUG-023 — /idle*: шапка «окно: …» затёрта длительностью — дата начала окна не читается

- Статус: ЗАКРЫТ (был ОТКРЫТ, закрыт 2026-09-09)
- Фикс: `src/bot/mon.zig` (отдельный `sbuf` для длительности в fmtIdle) + тест
- Открыт: 2026-09-09
- Где найдено: код-ревью (злой QA, TC-148)
- Серьёзность: средняя

## Симптом

Шапка отчёта простоя вместо «окно: 09.09.2026 02:30 — 14:30 … длина 12 ч»
печатает смесь: дата начала заменяется длительностью окна с мусорным
хвостом («окно: 12 ч…026 14:30»).

## Причина

`src/bot/mon.zig:340-346`: `fmtDateTimeLocal(&fbuf, …)` (2-й аргумент
print) и `fmtSpan(&fbuf, …)` (5-й аргумент) делят один буфер `fbuf` —
второй вызов затирает первый, длина слайса от первого остаётся (16 байт
даты), на печати — префикс длительности + обрезанные байты.

## Лечение

Раздельные буферы для даты и длительности (как `tbuf` уже отдельный).

## Профилактика

Тест fmtIdle с фиксированным окном: шапка содержит и дату «дд.мм.гггг»,
и «длина …», без наложения.
