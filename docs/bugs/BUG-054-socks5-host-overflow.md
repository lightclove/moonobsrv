# BUG-054 — SOCKS5 buildConnect: домен > 255 переполнял стек-буфер (assert выключен в релизе)

- Статус: ЗАКРЫТ (был ОТКРЫТ, закрыт 2026-09-10)
- Фикс: `src/net/socks5.zig` (buildConnect → ?[]const u8: пустой/длиннее 255/буфер мал → null → SocksBadHost) + тест
- Открыт: 2026-09-10
- Где найдено: код-ревью (ночной аудит протоколов)
- Серьёзность: низкая (латентная: единственный вызов — константа api.telegram.org)

## Симптом

host длиннее 255: байт длины обрезался (@min), memcpy писал весь host в
262-байтный буфер кадра + порт за границей; защита — std.debug.assert,
выключенный в ReleaseSmall.

## Причина

Протокол ограничивает домен байтом длины (255), код молча обрезал только
поле длины.

## Лечение

buildConnect возвращает null для пустого/сверхлимитного домена и малого
буфера; handshake — error.SocksBadHost.

## Профилактика

Тест «домен вне лимита протокола — null, не UB».
