# BUG-010 — тарболл Zig недоступен с прода (404, затем таймаут сети)

- Статус: ЗАКРЫТ (было ОТКРЫТ, закрыт 2026-09-09)
- Открыт: 2026-09-09
- Где найдено: прод (сборка bot-образа)
- Серьёзность: средняя
- Фикс: `deploy.ps1` (кросс-сборка) + `Dockerfile` (runtime-only)

## Симптом

Сборка в контейнере падала: сначала 404 на
`zig-linux-x86_64-0.15.2.tar.xz` (сменилась схема имён на
`zig-x86_64-linux-*`), после переименования — `curl: (56) Connection timed
out`: ziglang.org с прода не качается.

## Причина

Прод не должен вообще ничего собирать и скачивать — эта зависимость
была архитектурной ошибкой, а не только сетевой.

## Лечение

Бинарь кросс-компилируется на dev-машине
(`z.cmd build -Drelease -Dtarget=x86_64-linux-musl` → `dist/`), Dockerfile
стал runtime-only: alpine + сертификаты + готовый файл.

## Профилактика

Правило: в прод-образе — ни загрузок, ни компиляторов. Доставлять артефакт.
