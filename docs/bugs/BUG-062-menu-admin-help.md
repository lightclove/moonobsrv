# BUG-062 — кнопка «Меню команд» показывала админу урезанный список

- Статус: ЗАКРЫТ (был ОТКРЫТ, закрыт 2026-09-10)
- Фикс: `src/bot/cb.zig` (admin передан в onMenu → helpText(admin))
- Открыт: 2026-09-10
- Где найдено: код-ревью (ночной аудит фич)
- Серьёзность: низкая

## Симптом

`menu:main` собирал helpText всегда с admin=false — админ терял строку
«🔧 Админ: /monitor · /restart …» в меню, хотя /help показывал её.

## Причина

Флаг admin вычислялся в handle(), но в onMenu не передавался.

## Лечение

admin прокинут в onMenu.

## Профилактика

Ручная проверка C7 от админского аккаунта.
