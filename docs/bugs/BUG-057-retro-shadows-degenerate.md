# BUG-057 — тени ретро вырождены у всех планет, кроме Меркурия (окно поиска 30 сут)

- Статус: ЗАКРЫТ (был ОТКРЫТ, закрыт 2026-09-10)
- Фикс: `src/astro/retro.zig` (makeWindow: окна поиска теней 30 → 200 сут) + тест
- Открыт: 2026-09-10
- Где найдено: код-ревью + зонды (Венера: пересечения на −33/+32 сут — за окном)
- Серьёзность: средняя (сегодня тени печатает только /mercury — Меркурий корректен; мина для /venus…/saturn)

## Симптом

`Window.pre_shadow == start` и `post_shadow == end` у Венеры, Марса,
Юпитера, Сатурна, Урана, Нептуна, Плутона: инвариант pre < start < end <
post нарушен для 7 из 8 тел. Причина — медленные дуги: возврат по градусу
станции занимает 32–100+ суток, окно поиска было 30.

## Причина

Константа 30 сут подобрана под Меркурий (~20/+18 сут) и не пересматривалась
при расширении на внешние планеты.

## Лечение

Окна поиска pre/post-тени — 200 суток (Плутон ~104 сут с запасом); скан
останавливается на первом пересечении, стоимость не меняется для быстрых тел.

## Профилактика

Тест «ретро-тени: строго обрамляют окно у Венеры и внешних планет».
