# BUG-032 — subsSnapshot молча режет рассылку по буферу вызова (128 подписчиков)

- Статус: ЗАКРЫТ (был ОТКРЫТ, закрыт 2026-09-09)
- Фикс: `src/bot/store.zig` (лог усечения) + буферы рассылки 128 → 256 в `src/features/*`
- Открыт: 2026-09-09
- Где найдено: код-ревью (злой QA)
- Серьёзность: низкая

## Симптом

Подписчики сверх 128 тихо выпадают из всех уведомлений (VOC, Меркурий,
лунные дни): ватчики передают `[128]i64`, `subsSnapshot` копирует
минимум без диагностики.

## Причина

`src/bot/store.zig:350-356` + вызовы `var snap: [128]i64` во всех
`on_tick` (features/voc.zig, mercury.zig, lunday.zig, planets.zig).

## Лечение

Логировать предупреждение при усечении (`subs > buf.len`); поднять
буферы вызова до 256. Для личного бота 128 вряд ли достижимо, но молчать
о потере — нельзя.

## Профилактика

Тест: 130 подписчиков → в лог попадает предупреждение (проверка через
возвращаемое усечённое значение не строится без лог-хука — фиксировано
ручной проверкой D1 при нагрузке; минимум — тест, что 128 влезают без
потерь).
