# BUG-059 — SOCKS5: IPv6-литерал в скобках конфигурировался, но прокси всегда был «мёртв»

- Статус: ЗАКРЫТ (был ОТКРЫТ, закрыт 2026-09-10)
- Фикс: `src/config.zig` (parseSocks снимает [..]) + `src/net/socks5.zig` (ATYP=0x04 для IPv6) + тесты
- Открыт: 2026-09-10
- Где найдено: код-ревью + зонды (parseIp(«[::1]») = false)
- Серьёзность: низкая (актуально для не-Tor прокси в LAN)

## Симптом

`MOONOBSRV_TOR=socks5://[::1]:9050` принимался конфигом, но host оставался
«[::1]» со скобками: ни parseIp, ни getaddrinfo такой хост не резолвят —
проба прокси всегда FAIL (ложные алерты «Telegram недоступен», холостые
авто-рестарты Tor). Даже при коннекте кадр CONNECT нёс ATYP=0x03 с
«доменом» [::1] — RFC 1928 требует ATYP=0x04 для IPv6.

## Причина

parseSocks не знал о скобочной форме RFC 3986; buildConnect умел только
домен.

## Лечение

parseSocks снимает скобки; buildConnect кодирует IPv6-литерал как ATYP=0x04
(16 байт адреса), домен — по-прежнему ATYP=0x03 (socks5h).

## Профилактика

Тесты: parseSocks(«[::1]:9050») → host «::1» (проверен parseIp);
buildConnect v6 — байт-в-байт ATYP=4.
