# BUG-030 — /idle*: «… ещё N» занижает число скрытых промежутков (кап 16 при показе 12)

- Статус: ЗАКРЫТ (был ОТКРЫТ, закрыт 2026-09-09)
- Фикс: `src/bot/mon.zig` (`Stat.spans_lost`, «… ещё N + lost») + тест
- Открыт: 2026-09-09
- Где найдено: код-ревью (злой QA)
- Серьёзность: низкая

## Симптом

При большом числе отключек (мешают бутлупы) админ видит 12 промежутков и
«… ещё 4», когда реально скрыто больше: массив spans переполняется на 16
и последующие молча отбрасываются, счётчик «ещё» считает только до
16-го.

## Причина

`src/bot/mon.zig:256-266` (addSpan молча теряет сверх 16) и `:391-393`
(`span_n − IDLE_SPANS_SHOW` по заполненному до предела span_n).

## Лечение

Считать потерянные: поле `spans_lost` в Stat, инкремент в addSpan при
переполнении; «… ещё {span_n − SHOW + spans_lost}».

## Профилактика

Тест computeStats: 20 неслипшихся гэпов → в отчёте «ещё 8» (не «ещё 4»).
