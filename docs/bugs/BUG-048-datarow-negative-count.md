# BUG-048 — отрицательный count колонок DataRow → @intCast в usize → UB

- Статус: ЗАКРЫТ (был ОТКРЫТ, закрыт 2026-09-10)
- Фикс: `src/db/pg.zig` (parseDataRow: n < 0 → PgProtocol) + тест
- Открыт: 2026-09-10
- Где найдено: код-ревью (паника @intCast доказана зондом на кадре FF FF)
- Серьёзность: средняя

## Симптом

Кадр DataRow с отрицательным i16-count (битые/злонамеренные серверные
данные) → `@intCast(i16 → usize)` → паника в Debug, UB в ReleaseSmall
(прод) — единственная непроверенная граница в разборе протокола.

## Причина

`arena.alloc(Value, @intCast(n))` без проверки знака; соседние границы
(длины колонок, i+4 > body.len) проверялись.

## Лечение

`if (n < 0) return Error.PgProtocol;`

## Профилактика

Тест parseDataRow на {0xFF,0xFF} → ошибка, не паника.
