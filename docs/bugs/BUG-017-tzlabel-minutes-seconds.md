# BUG-017 — tzLabel: дробные часовые пояса печатаются в секундах («UTC+5:1800»)

- Статус: ЗАКРЫТ (был ОТКРЫТ, закрыт 2026-09-09)
- Фикс: `src/util.zig` (`tzLabel`: остаток делится на 60) + тест
- Открыт: 2026-09-09
- Где найдено: тесты (злой QA, прогон TC-062 из docs/TESTCASES_AAA.md)
- Серьёзность: низкая

## Симптом

`/status` (и везде, где печатается метка пояса) для дробного смещения
показывает абсурдную метку:

- UTC+5:30 (Индия, `MOONOBSRV_TZ=5.5`) → «UTC+5:1800»;
- UTC−4:30 (`MOONOBSRV_TZ=-4.5`) → «UTC-4:1800».

Целые пояса и МСК/UTC отображаются корректно, поэтому баг незаметен на
дефолтной конфигурации (Москва).

## Причина

`src/util.zig`, `tzLabel`: остаток `@mod(off_sec, 3600)` — это секунды
(1800), а печатается он как будто минуты: `...{d}:{d:0>2}` без деления
на 60. Существующий тест проверял только «МСК».

## Лечение

`const m_sec = @mod(off_sec, 3600); const m: u32 = @intCast(@divTrunc(m_sec, 60));`
— после чего «UTC+5:30», «UTC-4:30».

## Профилактика

Тест в `src/util.zig`: tzLabel(19800) == "UTC+5:30", tzLabel(-16200) ==
"UTC-4:30", tzLabel(10800) == "МСК", tzLabel(0) == "UTC", tzLabel(3600) ==
"UTC+1".
