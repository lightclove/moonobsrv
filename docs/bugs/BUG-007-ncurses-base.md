# BUG-007 — ncurses-base не существует в alpine 3.22

- Статус: ЗАКРЫТ (было ОТКРЫТ, закрыт 2026-09-09)
- Открыт: 2026-09-09
- Где найдено: прод (сборка tor-образа)
- Серьёзность: низкая
- Фикс: `ci/tor/Dockerfile`

## Симптом

`apk add ncurses-base` → «no such package», tor-образ не собирается,
первый деплой упал.

## Причина

Пакет добавлен «на всякий случай» для `nc` в healthcheck — а в alpine
`nc` уже есть в busybox.

## Лечение

Пакет убран; healthcheck с busybox-`nc` работает.

## Профилактика

Не добавлять пакеты «про запас»; в alpine сначала проверить, что умеет
busybox.
