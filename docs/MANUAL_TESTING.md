# MANUAL_TESTING.md — план ручного тестирования moonobsrv

Документ системного аналитика к `FEATURES.md` / `TESTCASES_AAA.md`
(версия 1.1.0, 2026-09-09). Ручной прогон закрывает то, что нельзя проверить
юнитами: живой Telegram, кнопки, админский контур на проде, деплой.
Правило команды: **каждый пуш/фикс уходит только после прохода этого плана**
(разделы A–C обязательны всегда; D–F — при затронутых областях).

Сокращения результата: PASS / FAIL / BLOCKED (нет окружения) / SKIP (не
затронуто). Каждый FAIL — карточка в `docs/BUGS.md` в тот же ход.

## G. Регресс перед каждым пушем фикса (чек-лист)

1. `z.cmd build test` — зелёные.
2. `--today` — блоки на месте, даты адекватные.
3. Затронутая фича прогнана по разделу C (или D/E, если это админка).
4. Карточка бага закрыта (Статус: ЗАКРЫТ, Лечение/Профилактика заполнены).
5. Строка в `docs/CHANGELOG.md` ([Unreleased] → Исправлено) с датой.
6. Версия `runtime.version` актуальна (PATCH на пачку фиксов релиза).
