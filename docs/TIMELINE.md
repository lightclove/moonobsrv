# Хронология moonobsrv

Даты и интервалы — по местному времени (МСК); до появления git-истории — по
меткам времени файлов (надёжно для «ночи» и «дня», не для минут). Версии и
детали — [CHANGELOG.md](CHANGELOG.md).

## 2026-09-09, первая ночь (02:14–04:48) — 1.0.0: астробот

- Выбран стек: чистый Zig 0.15.x, ноль внешних зависимостей, тулчейн вложен
  в проект (`tools/zig-0.15.2`) — сборка самодостаточна.
- Астроядро на чистых функциях (`f64 → f64`, без аллокатора): время
  (Unix↔JD), углы/бисекции, Солнце (Meeus 25, ±0.01°), Луна (усечённый
  ELP2000, ±0.05°), планеты по Кеплеру (Standish JPL), птолемеевские
  аспекты, VOC через ингрессии+аспекты, станции и тени ретро, лунные дни.
- Бот на std.http.Client: /voc /mercury /day и планеты, подписки,
  long polling + webhook-режим, state.json с атомарной записью.
- Тесты-якоря по реальным событиям: затмения 12.08.2026 и 03.03.2026,
  ретро-окна Меркурия 2026–2027, ингрессия Луны 09.09.2026 22:36 МСК.
- Релизная диета: ReleaseSmall, strip, gc-sections, без libc — 752 КБ.
- Срез зафиксирован README 04:48 — это релиз 1.0.0.

## 2026-09-09, вторая половина ночи (05:26–05:59) — ядро порта из rbot

Задача: перенести в moonobsrv операционный контур rbot (мониторинг слоёв,
рестарты, стоп-краны, idle-статистика, визард, доступ, Tor, БД), не таща
ни строчки Rust. TDD: модули начинаются с тестов.

- `net/socks5.zig` — кадры RFC 1928 байт-в-байт + handshake с фейковым
  прокси в тестах (тестами же поймана длина доменного кадра).
- `net/https.zig` — TLS 1.3 + HTTP/1.1 на std.crypto.tls вместо
  std.http.Client; попутно открыт квирк std 0.15.2: takeDelimiterExclusive
  не съедает разделитель — перешли на Inclusive с ручным тримом.
- `db/pg.zig` — wire-протокол PostgreSQL v3 (startup, trust/md5, Q);
  фейк-сервер в тестах прогоняет весь обмен, пойманы порядок байтов и +1
  в длине кадров.
- `bot/wd.zig` (heartbeat/bounce/inflight/offset, бэкофф, пробы, Docker
  Engine API над unix-сокетом), `bot/mon.zig` (/monitor, маски, idle-окна
  и статистика), `bot/rst.zig` (таргеты, план, стоп-краны, batch-brake),
  `bot/access.zig` + `bot/cb.zig` (заявки, колбэки), `features/wizard.zig`
  (22+3 слайда), `features/monitor.zig`, новый цикл polling, hostwatch.
- Схема БД: app_user / layer_sample / bot_kv / tg_inbox; двойной бэкенд
  стора (Postgres или JSON-фолбэк).
- 73/73 теста.

  бутстрапу; deploy.cmd → ci/deploy.ps1 → ci/remote-apply.sh.

  (те же, что у rbot; torrc вынесен из репозитория). Tor: healthy.

  сокет-писателя 8 КБ < tls.min_buffer_len ≈ 17 КБ — в ReleaseSmall это
  UB → буферы 17 КБ; (2) flush TLS-писателя не отправляет шифротекст в
  сокет — добавлен flush сокет-писателя. Итог: `HTTP/1.1 200 OK` через Tor.
- Прод стабилен: bot/db/tor healthy, Postgres подключён, 37 команд,
  long poll через Tor. linux-musl бинарь — 715 КБ (меньше 752 КБ у 1.0.0
  при большем функционале: std.http.Client выброшен).
